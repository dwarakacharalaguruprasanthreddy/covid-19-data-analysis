# COVID-19 Data Analysis and Visualization

## Project Overview
This project focuses on analyzing COVID-19 data to identify trends and patterns in confirmed cases and deaths across different countries. Python libraries are used for data cleaning, preprocessing, exploratory data analysis (EDA), and data visualization.

## Objectives
- Analyze COVID-19 confirmed cases and death cases.
- Identify the top 10 countries with the highest confirmed cases.
- Understand country-wise COVID-19 death distributions.
- Compare confirmed cases and death cases.
- Identify relationships between COVID-19 data variables.
- Present insights through visualizations and KPIs.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Dataset
The project uses a COVID-19 dataset containing country-wise and date-wise information about confirmed cases, deaths, and newly reported cases.

## Data Cleaning and Preprocessing
- Removed unnecessary columns.
- Checked and handled missing values.
- Converted date columns into the appropriate format.
- Checked duplicate records.
- Identified negative values in newly reported cases and deaths.
- Prepared the dataset for analysis.

## Exploratory Data Analysis and Visualizations
The project includes:
1. Top 10 countries by confirmed COVID-19 cases.
2. Top 10 countries by death cases.
3. Comparison of confirmed cases and death cases.
4. Correlation heatmap to understand relationships between numerical variables.

## Key Performance Indicators (KPIs)
- Total number of countries.
- Total confirmed cases.
- Total death cases.
